# Tech Quiz App
A modern and interactive **Quiz Web Application** built using **HTML, CSS, and JavaScript**.  
This project tests users' knowledge with multiple-choice questions and provides instant feedback with a clean and responsive UI.


## Features
- 10 curated technical questions
- Instant answer validation (correct / incorrect)
- Final score with percentage
- Restart quiz functionality
- Clean and minimal UI design
- Fully responsive layout
- Smooth hover and interaction effects


## Tech Stack
- **HTML5** – Structure of the application  
- **CSS3** – Styling, layout, and responsiveness  
- **JavaScript (Vanilla JS)** – Logic and interactivity

## How It Works
1. User clicks **Start Quiz**
2. Questions are displayed one by one
3. User selects an answer
4. Correct answer is highlighted
5. User proceeds using **Next button**
6. Final score is displayed at the end


## UI Overview
- Clean card-based layout
- Two-column option grid (responsive)
- Color-coded feedback:
  - Green → Correct
  - Red → Incorrect
